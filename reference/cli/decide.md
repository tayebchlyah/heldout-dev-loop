# decide

- `decide --kind decision|discovery --what <text> --why <text> --evidence <text> [--result <text>] [--risk] [--feature <slug>] [--repo <path>]`: appends one row to the decision log. Feature: `--feature`, else the branch `<prefix>/<slug>` (HEAD detached by a rebase: the branch the rebase rewrites). Log: the spec with `feature: <slug>` (section `## Decision log`), else (Track S, a branch worktree) `<git-dir>/dev-loop/decisions.md`. Section and header `| Time | Stage | Session | Kind | Risk | Decision | Why | Evidence | Result |` added at the end when absent; a row goes after the last table line of the section. `Time` UTC `YYYY-MM-DDTHH:MMZ`, `Stage` the `status` stage, `Session` first 8 characters of `CLAUDE_CODE_SESSION_ID`, else `CODEX_THREAD_ID`, else empty. In a cell `|` becomes `\|`, line breaks one space. Lock `<git-common-dir>/dev-loop/decide.lock`, temp file and rename. JSON `file`, `row`. Exit 1 with `error`, nothing written: no feature, notes path unresolved, no spec and no branch worktree, an empty `--what`, `--why` or `--evidence`, a log that cannot be read or written. Exit 2: usage, `--kind` not one of the two.
