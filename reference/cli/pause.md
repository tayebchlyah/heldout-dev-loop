# pause

- `pause [--event] [--intent <t>] [--verified <t>] [--open <t>] [--next <t>] [--agent <id>=<task> ...] [--run <log> ...] [--feature <slug>] [--repo <path>]`, `pause --clear [--feature <slug>] [--repo <path>]`: writes `<git-dir>/dev-loop/pause.json` (the worktree's own git dir), a new pause replaces it. Fields `at`, `reason` (`manual`, or the hook `error`), `message` (`last_assistant_message`, else `error_details`), `harness`, `session`, `transcript` (`--event`: `transcript_path`; else the first `$CLAUDE_CONFIG_DIR/projects/*/<session>.jsonl` (default `~/.claude`) or `$CODEX_HOME/sessions/**/rollout-*-<session>.jsonl` (default `~/.codex`)), `feature` (`--feature`, lower case; else the slug of the branch `<prefix>/<slug>`; HEAD detached by a rebase: of the branch the rebase rewrites, as `status` reads it; a Shaping pause on `main` gives `--feature`, so `status --feature <slug>` finds the note), `stage` (the `status` stage of that `--feature`; else of the checkout), `ledger_last`, `dirty` (`git status --porcelain` paths), `last_decision` (last log row), `agents`, `runs`, `intent`, `verified`, `open`, `next`. `--event`: `StopFailure` JSON on stdin, `harness` `claude`; `cwd` not a feature worktree (linked worktree, branch with `/` (a rebase in progress: the branch it rewrites), `dev-loop.json` at its top): `{"skipped": "not-a-feature-worktree"}`; not a JSON object: `{"skipped": "bad-input"}`, exit 0. JSON `file`, `note`. `--clear`: `cleared` true or false; with `--feature`, only a note whose `feature` is that slug is removed, another stays (`cleared` false). Exit 1 with `error`: not a git repo. Exit 2: `--clear` with another option, `--event` with an intent, agent or run option, `--agent` without `=`.
