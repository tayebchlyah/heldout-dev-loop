# pause

- `pause [--event] [--intent <t>] [--verified <t>] [--open <t>] [--next <t>] [--agent <id>=<task> ...] [--run <log> ...] [--repo <path>]`, `pause --clear [--repo <path>]`: writes `<git-dir>/dev-loop/pause.json` (the worktree's own git dir), a new pause replaces it. Fields `at`, `reason` (`manual`, or the hook `error`), `message` (`last_assistant_message`, else `error_details`), `harness`, `session`, `transcript` (`--event`: `transcript_path`; else the first `$CLAUDE_CONFIG_DIR/projects/*/<session>.jsonl` (default `~/.claude`) or `$CODEX_HOME/sessions/**/rollout-*-<session>.jsonl` (default `~/.codex`)), `feature`, `stage`, `ledger_last`, `dirty` (`git status --porcelain` paths), `last_decision` (last log row), `agents`, `runs`, `intent`, `verified`, `open`, `next`. `--event`: `StopFailure` JSON on stdin, `harness` `claude`; `cwd` not a feature worktree (linked worktree, branch with `/`, `dev-loop.json` at its top): `{"skipped": "not-a-feature-worktree"}`; not a JSON object: `{"skipped": "bad-input"}`, exit 0. JSON `file`, `note`. `--clear`: `cleared` true or false. Exit 1 with `error`: not a git repo. Exit 2: `--clear` with another option, `--event` with an intent, agent or run option, `--agent` without `=`.
