# review-merge

- `review-merge <reviewer>=<file> [...]`: Stage 6 triage merge. Per file: the first Markdown table whose header holds `file`, `line`, `finding`, `class`, `verdict` (any case, any order, other columns ignored; text around it ignored). Cell: spaces and one pair of backticks stripped, `\|` a pipe. `file`: `^.*?/devloop-second-review-<any>/` removed, then the worktree top and `/`, then a leading `./`. `line`: integer, an `L` before it dropped, `a-b` gives `a`; empty, `-`, `n/a`: null. `class` (lower case): `correctness`, `security`, `spec`, `standards`. One row per `file` and `line` (null a value), sorted by `file` then `line` (null first), `n` from 1. JSON `rows` (`n`, `file`, `line`, `reviewers` in argument order, `findings` `{reviewer, finding, class, verdict}`), `counts` (findings per reviewer, 0 too), `security` (the `n` of rows with a `security` finding). Exit 1 with `error`, `file` (the argument path), `row` (1 for the first data row, null when no table): no table, a cell count other than the header's, empty `file` or `finding`, bad `line`, bad `class`. Header with no data row: 0 findings. Exit 2: no argument, no `=` or an empty side, a reviewer twice, a file not readable.
