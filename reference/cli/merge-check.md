# merge-check

- `merge-check [--repo <path>] [--feature <slug>]`: the Stage 7 merge decision. Worktree: `git rev-parse --show-toplevel` of `--repo`, `head` its `HEAD`, slug the last `/` segment of its branch, lower case; never another worktree. `--feature <slug>`: the one branch of `refs/heads` whose name ends with `/<slug>`, case ignored; its worktree from `git worktree list` (mid-rebase too, from the rebase state), else `head` is `refs/heads/<branch>`. `track` from spec `track:`, `S` with no spec. `<main-ref>`: `refs/remotes/origin/main`, else `refs/heads/main`, fully qualified (a local tag or branch `origin/main` cannot shadow it). `merge` and `merge_human_paths` from `git show <main-ref>:dev-loop.json`, never the branch. Reasons (`reason` plus its fields): `config-unreadable` (absent, not a JSON object, or a bad `merge` or `merge_human_paths` value, an item empty after strip or ending in `/` too: fails closed), `merge-human`, `track-l`, `human-path` (`path`, `pattern`: each path of `git diff --name-only --no-renames --ignore-submodules=none <main-ref>...HEAD` a pattern matches, first pattern wins), `config-changed` (`merge`, `merge_human_paths`, `file_size_exempt` (absent: `[]`; a bad value is compared as it is, never `config-unreadable`) or `commands` (absent: null; any difference in the whole object) in the `HEAD` copy differs; a `HEAD` copy absent or not parsing counts, unless `<main-ref>` has none of the four, an empty `file_size_exempt` counting as none), `harness-config` (`path`: each path of that diff that is `.mcp.json`, or is `.claude`, `.codex` or `.dev-loop` itself (a symlink, file or submodule there) or under `.claude/`, `.codex/`, `.dev-loop/` or `.agents/skills/dev-loop/`, case ignored: the agent sandbox, the host-run hooks, rules, agents and MCP server commands; a kit upgrade PR always waits for the user; whatever `merge_human_paths` says, with `config-unreadable` too), `no-review` (no reviewed head, a token that is not 7 to 40 hex characters, or not a commit), `unreviewed` (`commit`, `paths`: its code paths, all its paths when its diff fails)., `dropped` (`commit`: a reviewed commit with a non-empty patch-id that no landing commit carries and `git cherry <main-ref> <reviewed> <base>` does not mark `-`, for example a fix skipped in a rebase). With `config-unreadable`, `merge-human`, `human-path` and `config-changed` are not computed. Reviewed head: the sha of the last ledger line `Feature gate: green at <sha>` (Tracks M and L), else of `<git-dir>/dev-loop/review-done` (Track S). Each commit of `<main-ref>..HEAD` against its first parent: `git patch-id --verbatim` (whitespace kept, implies `--stable`) of its diff (`--no-ext-diff --no-textconv --no-color --no-renames --ignore-submodules=none -a`: a `.gitmodules` or user `ignore = all` cannot hide a submodule pointer move), each non-empty patch-id of `$(git merge-base <reviewed> <main-ref>)..<reviewed>` counted, a reviewed patch-id vouches for one landing commit only: the landing commits oldest first, one whose patch-id still has a count left is reviewed and takes one count; an empty diff is skipped. Not reviewed with a code path, or a diff git cannot compute: `unreviewed`. Only test or doc paths: in `unreviewed_minor`, no block. Test or doc path, first rule that holds: a folder segment `.github`: code; a folder segment `tests` or `test`: test (a config file there is test data); a config file type (name ending, case ignored, with `.yml`, `.yaml`, `.json`, `.toml`, `.ini`, `.cfg` or `.conf`): code; a folder segment `docs` and a doc file type (`.md`, `.rst`, `.txt`, `.adoc`, `.png`, `.jpg`, `.jpeg`, `.gif`, `.svg`, case ignored): doc; a name `test_*.py`, `*_test.py`, `*_test.go`, `*.test.*`, `*.spec.*`, `README.md`, `CHANGELOG.md`: test or doc. Any other path is code, kit Markdown too (a kit's Markdown is its behaviour). Folder segments match case-sensitive. JSON `merge` (`human` when `reasons` is not empty, else `auto`), `reasons`, `reviewed` (the full sha, resolved in the feature worktree, or null), `head` (the full sha checked), `branch` (the full branch name), `unreviewed_minor` (`commit`, `paths`), `feature`, `track`. Bytes that are not UTF-8 in the branch `dev-loop.json` (counts as not parsing), a path name or the ledger never crash it. Exit 0. Exit 1 with `error`: no feature (a branch without `/` or a detached `HEAD` and no `--feature`, or no branch `<prefix>/<slug>`), `--feature` matching more than one branch (`error` names each, sorted), notes path unresolved, no `<main-ref>`, a git failure reading `HEAD`, a path list or a commit list (worktree folder gone, no merge base: fails closed, no `merge`). Exit 2 usage.
