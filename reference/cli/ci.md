# ci

- `ci wait [--pr <n>] [--timeout <min>]`: one PR verdict for the local `HEAD`. `git rev-parse HEAD` fails: `error`, no gh call. Each pass (first at once, then every 30 s, `DEVLOOP_TEST_CI_POLL` seconds, test only): `gh pr view --json` (`headRefOid`, `mergeable`, `mergeStateStatus`, `isDraft`, `reviewDecision`, `latestReviews`, `statusCheckRollup`, ...), `headRefOid` not `HEAD`: poll again; else `gh api graphql` review threads (first 100, owner and repo from the PR `url`). First rule wins: `CONFLICTING` or `DIRTY`: `conflicts`; an unresolved thread (outdated too): `threads`; a latest review `CHANGES_REQUESTED`: `blocked` `changes-requested`; a failed check: `fail`; a pending check, no check, `UNKNOWN`: poll again (deadline: `timeout`, `pending` names); draft: `blocked` `draft`; `BEHIND`: `blocked` `behind`; `BLOCKED`: `blocked` `review-required`, `changes-requested` or `rule`; else `pass`. `fail` and `blocked`: `stale_base` from `gh api repos/<o>/<r>/compare/<base>...<head>` `behind_by` (above 0 true, a failure null). `fail`: `failed_job`, `url` (the check link), `first_error` (`gh run view <id> --log-failed`, first error block, at most 30 lines). JSON `state`, `reason`, `url`, `head`, `failed_job`, `first_error`, `stale_base`, `threads` (`path`, `line`, `author`, `url`, `text`: first line of the first comment, at most 200 characters, only when its `authorAssociation` is `OWNER`, `MEMBER` or `COLLABORATOR`, else null: a public repository lets any GitHub user comment), `pending`, `message` (`error` only; the first `gh pr view` with "no pull requests found": `no-pr`). Every gh call 60 s max, a hang is a failed call. Exit 0 only for `pass`. Never calls `checks --watch` or `run rerun`.
