# release-plan

- `release-plan [--repo <path>] [--harness claude|codex] [--profile quick|standard|deep] [--budget <n>]`: run in the main worktree at the commit to audit. JSON `run` (`run-<N>`), `output` (created), `head`, `first` (no current record), `profile` (`quick` first, else `standard`), `budget` (100 first, else null), `scope` (`whole`, or `<base>..<head>`), `base` (null when first; the record sha when an ancestor of `HEAD`, else the merge base, none: null and `whole`), `prior_runs`, `sandbox` (`engine`, `images`, `runner`), `skill`. Exit 1 with `error`, nothing created: `dirty` (`paths`), `placeholder` (`files`, an iCloud placeholder under `$NOTES/security-audit/`), `run-folder-exists`, `no-project-note`, notes path unresolved, `cannot read <note>: <ExcType>`, `git status failed`, `cannot resolve HEAD`.
