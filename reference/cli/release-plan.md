# release-plan

- `release-plan [--repo <path>] [--harness claude|codex] [--profile quick|standard|deep] [--budget <n>]`: run in the main worktree at the commit to audit. JSON `run` (`run-<N>`), `output` (created), `head`, `first` (no current record), `profile` (`quick` first, else `standard`), `budget` (100 first, else null), `scope` (`whole`, or `<base>..<head>`), `base` (null when first; the record sha when an ancestor of `HEAD`, else the merge base, none: null and `whole`), `exclude` (sorted paths out of the audit scope: the kit copies of an upgrade; `[]` unless `base` is the record sha and the `.dev-loop/MANIFEST.json` `version` at `base` differs from the one at `HEAD`; then each MANIFEST `files` key under a kit root (`.agents/skills/`, `.claude/agents/`, `.claude/skills/`, `.codex/agents/`, `.codex/rules/`, `.dev-loop/hooks/`) whose `HEAD` tree entry matches it (`sha256:<hex>`: a regular file of that SHA-256; `link:<target>`: a symlink to that target), plus the MANIFEST, changed in `<base>..<head>`; never a deleted copy, `dev-loop.json` or a merged config file), `prior_runs`, `sandbox` (`engine`, `images`, `runner`), `skill`. Exit 1 with `error`, nothing created: `dirty` (`paths`), `placeholder` (`files`, an iCloud placeholder under `$NOTES/security-audit/`), `run-folder-exists`, `no-project-note`, notes path unresolved, `cannot read <note>: <ExcType>`, `git status failed`, `cannot resolve HEAD`.
