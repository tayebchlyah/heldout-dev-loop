# metrics

- `metrics [--repo <path>] [--feature <slug>] [--write]`: token cost of each stage of a feature, plus its numbers, from local Claude transcripts (Codex not counted). Feature as `status` finds it, worktree required. Transcripts: `$CLAUDE_CONFIG_DIR/projects`, else `~/.claude/projects`; per worktree of `git worktree list` (main too) the folder named after its path, each character not `A-Za-z0-9` as `-`; `*.jsonl` plus `<session>/subagents/agent-*.jsonl` with `.meta.json`; read by first `timestamp`, then path; a bad line skipped; a repeated `uuid` (resumed session) skipped for counts, checked over main transcripts only (a resumed session), a subagent record is never a copy; still read for attribution. Feature of a record: latest mention at or before it (a `tool_use` input holding a feature worktree path followed by `/`, `"`, space or end, or a `Bash` `devloop.py board ... --claim <slug>`); records before the first mention: the first mention's feature; no mention: none. Subagent: the feature of the record holding its `toolUseId`. Stage: board `board-state.json` `stage_times` keys `3` to `7` as boundaries, before the first `1-2`; no state, no entry, `backfilled` with a spec (Track S ignores it) or no boundary: `unattributed`, `stages` `{}`. Weight (input-equivalent tokens), once per `message.id`: input x1, 5m cache write x1.25, 1h x2, cache read x0.1, output x5; no `cache_creation` object: `cache_creation_input_tokens` as 5m. JSON `feature`, `track` (`S` with no spec), `shipped`, `sessions`, `active_hours` (gaps of 300 s or less), `user_messages` (typed prompts), `gate` (`runs`, `seconds` of `gate --summary` results), `tests` (`unit`, `acceptance`: `def test_`, `it(`/`test(`, `func Test` lines added minus removed in `<merge-base>...HEAD`), `denials` (by hook `.sh` name, else `other`), `unattributed`, `stages` (`weighted`, `models`: raw kinds per model), `total`, `agents` (`type`, `description`, `weighted`, `seconds`), `effort` (`{<stage>: {<role>: {<level>: <count>}}}`: each `api-request` record of the feature, not a copy, its stage from its `timestamp`, role `main` for a main transcript, else the subagent `.meta.json` `agentType`, `?` when absent; level `params.output_config.effort` when one of `low`, `medium`, `high`, `xhigh`, `max`, else `?`; unattributed: `{}`), `row`, `file`. `--write`: the row in `$NOTES/Feature Metrics.md` (made with frontmatter, `# Feature Metrics`, the cost data rule, the header); a row of the slug replaced, its `escaped` cell kept; else after the last table line; temp file and rename. Row cells in thousands; a stage absent from `stage_times`: `-`; unattributed: `?`. Header column `effort` between `total` and `escaped`: per stage of `1-2`, `3` to `7`, `<stage>:<code>` joined by one space, from the `main` role: the level with the most requests, a tie to the higher level, code `l`, `m`, `h`, `xh`, `max`; no main request: `-`; only `?`: `?`; unattributed: the cell is `?`. Example: `1-2:h 3:h 4:h 5:m 6:m 7:m`. `--write` on a file whose header (first cell `feature`) has no `effort` column: header and separator replaced, a `?` cell before the last cell of each following table row, `escaped` kept. Exit 1 with `error`, nothing written: no feature, no worktree, notes path unresolved, `no transcript records for <slug>`, notes file unreadable or unwritable. Exit 2 usage.
