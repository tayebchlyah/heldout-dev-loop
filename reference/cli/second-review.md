# second-review

- `second-review --harness claude|codex [--timeout <minutes>]`: in the feature worktree, the other family's CLI (`codex` for `--harness claude`, `claude` for `--harness codex`) reviews the branch, correctness and security only, prompt `references/second-review.md`. Two locks: `"second_review": true` (a JSON boolean) in `dev-loop.json` at `<main-ref>` (as `merge-check`, never the branch; every git call with `GIT_NO_REPLACE_OBJECTS=1`), and `second_review` in the main worktree `dev-loop.local.json`: `false`, or an object keyed by `codex`, `claude`, each `false` or an object with optional `model` (a string, `re.fullmatch` `^[A-Za-z0-9][A-Za-z0-9._:/\[\]-]*$`) and `effort` (`codex`: `minimal`, `low`, `medium`, `high`, `xhigh`; `claude`: `low`, `medium`, `high`, `xhigh`, `max`; default `high`). Both files parsed with a duplicate key refused. First rule wins: no worktree or `HEAD`: `failed` `git`; no `<main-ref>`: `skipped` `no-main-ref`; no `dev-loop.json` there, key absent or `false`: `skipped` `project-off`; a copy that does not parse (not UTF-8 too), not an object, a key not a boolean: `failed` `bad-config`; local bad shape, or the local file tracked by git (`ls-files --error-unmatch` in the main worktree): `failed` `bad-config`; local `false`, or `false` for this reviewer: `skipped` `user-off`; no file (a folder there too), key or entry: `skipped` `not-chosen`; a rebase: `skipped` `rebase`; no merge base: `failed` `no-merge-base`; `<main-ref>..HEAD` empty: `skipped` `nothing-to-review`; no CLI: `skipped` `no-cli` (absolute `PATH` entries in order, a folder or resolved file inside a worktree of the repo skipped, `node` the same); export, record or prompt not made: `failed` `export`; output audit match: `tainted`, whatever the exit; past the timeout: `failed` `timeout`; exit other than 0: `failed` `exit <n>` (`message`: stderr tail; the CLI cannot start: `exit 127` for a missing file or interpreter, `exit 126` for one that cannot run, no record); no output or Claude `is_error`: `failed` `no-output`; else `done`. Export: `mkdtemp` prefix `devloop-second-review-` (inside a work tree: `failed` `export`), the tree of `HEAD` through `ls-tree -r -z` and `cat-file --batch` (no attributes), without `tests/acceptance/`, symlinks, submodules, `AGENTS.md`, `AGENTS.override.md`, `CLAUDE.md`, `CLAUDE.local.md`, `.mcp.json` at any depth, paths under a `.claude`, `.codex` or `.agents` folder, `.env`, `.env.*`, a blob over 1,048,576 bytes, a path with an empty, `.`, `..` or `.git` part, a file named `HEAD` at any depth (git never takes the export for a repository), a top-level `.second-review.diff` (file or folder), a path that is not valid UTF-8 (case ignored; a path whose case-folded form was written is left out; each counts in `left_out`); plus `.second-review.diff` (`<main-ref>...HEAD`, `--no-ext-diff --no-textconv --no-color -a`; drops only `tests/acceptance/`, `.env` and `.env.*`, case ignored: a change to `AGENTS.md`, `CLAUDE.md`, `.mcp.json`, `.claude/`, `.codex/` or `.agents/` stays in it as diff text). Removed when the run ends; each start sweeps prefix folders older than 24 h. Child: environment only `HOME`, `USER`, `LOGNAME`, `LANG`, `LC_ALL`, `TERM`, `TMPDIR`, plus `CLAUDE_CONFIG_DIR`, `CODEX_HOME` when set; `PATH` the CLI folder, the `node` folder, `/usr/bin:/bin:/usr/sbin:/sbin`; cwd the export, prompt on stdin, new session; after every run (a timeout too) `SIGTERM` to the group, `SIGKILL` 5 s later to what is left. Codex: `codex exec --ignore-user-config --ignore-rules --ephemeral --skip-git-repo-check -C <export>`, a read-only `devloop-review` permissions profile, `model_reasoning_effort`, `[-m <model>]`, `-o <file> -`, never `--sandbox`. Claude: `claude -p --restricted --strict-mcp-config --tools=Read,Grep,Glob --output-format json --effort <effort> [--model <model>]`. `--restricted` (`claude --help`, 2.1.310) removes the tools that run code and `WebFetch` unless `--tools` names them, confines the file tools to the working folders, and ignores the user, project and local settings files; managed settings and `--settings` still apply, and MCP servers still load without `--strict-mcp-config`. It does not stop a read of a file in the export: the export is the read limit. Audit: the `seal/audit.py` rule over the output, stdout and stderr against `tests/acceptance/`: a match gives `tainted`, `output` and `message` null, a taint record (`agent_type` `second-review`, no commits) in `taint.json` (`seal-check` `warnings`). Record `<git-common-dir>/dev-loop/second-review/<YYYYMMDDTHHMMSSZ>-<reviewer>/` (a taken name: `-2`, `-3`), written right before the CLI starts: `sent.txt` (one exported path per line, then the sha256 of the diff), `record.json` (`state` `running`, then the run JSON), after the run `stderr.log`, `output.md` (`tainted` removes both); `record` null, and no record folder, when the run stops before the CLI starts. JSON `state` (`done`, `skipped`, `failed`, `tainted`), `reason`, `message`, `reviewer`, `head`, `base`, `model`, `effort`, `endpoint` (`default`), `output` (`done` only), `files`, `left_out`, `seconds`, `tokens` (Claude `usage` input plus output, Codex the last `tokens used` number of stderr, else null), `record`. Exit 0 for `done`, `skipped`, `tainted`; 1 for `failed`; 2 usage (`--timeout` not a finite number above 0; default 15).
