# seal

- `seal --feature <slug> --message <subject> [--reverts <sha> ...]`: commits the staged change under `tests/acceptance/`. Reads the index, stages nothing. Message: subject, `This reverts commit <sha>.` per `--reverts`, `Acceptance: <slug>`, `Dev-Loop-Seal: <value>` (valid when either seal trailer matches; sha256 of one `<path> <blob>` line per staged path, sorted, blob `deleted` for a removal), `Dev-Loop-Seal-Patch: <value>` (sha256 of the `git patch-id --stable` of the `-U0` diff under `tests/acceptance/`). After the commit hooks ran, recomputes both from the commit and amends (`--no-verify`) when they or the message differ. Exit 1 with `error`: nothing staged under `tests/acceptance/`, a staged path outside it, slug not lower case words joined by `-`, a `--reverts` value that is not a commit. Exit 1 with `error` `file over the size limit` and `size` (the violations), no commit: a staged path under it over 40,000 bytes, new or grown against `<base>` (symlink, gitlink, binary skipped; no MANIFEST or exempt skip). Exit 2: both modes or neither. JSON `commit`, `seal`, `files`. Only `spec-tester` may run it (`git-guard.sh`).
- `seal --rebase-continue`: in a rebase, value from the index into the `Dev-Loop-Seal` trailer of the rebase commit message, and `Dev-Loop-Seal-Patch` (last paragraph only), then `git rebase --continue`, no editor. Exit 1 with `error`: no rebase, a staged path outside `tests/acceptance/`, nothing staged under it, "the stopped commit is not a seal commit" (no `Dev-Loop-Seal` trailer in its last paragraph), "nothing staged under the folder", "git rebase --continue failed" (the rebase ended without continuing). JSON `seal`, `files`, `rebase` (`continued`, or `stopped` with the next conflict and `conflicts`).
