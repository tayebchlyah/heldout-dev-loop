# gate

- `gate --summary`: `commands.gate`, else `scripts/gate.sh`. JSON `exit`, `log`, `seconds`, `failures`, `slowest` (JUnit XML in `DEVLOOP_REPORT_DIR`, else `[]` and `hint`), `seal` (the `seal-check --uncommitted` payload; the process exits 1 when `seal.ok` is false, even if the project gate passed; the JSON `exit` stays the project gate's own exit), `weakened` (list of `{path, reason}`, `reason` `skip-added` or `assertions-removed`, for test files in `git diff <base>`; report only, never changes the exit code), `size` (the `size-check --uncommitted` payload; the process exits 1 when `size.ok` is false).
