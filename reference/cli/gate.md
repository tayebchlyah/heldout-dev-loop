# gate

- `gate --summary`: `commands.gate`, else `scripts/gate.sh`. JSON `exit`, `log`, `seconds`, `failures` (each failed or errored JUnit case as `FAILED <classname>::<name>`, or `FAILED <file>::<name>` when the case has a `file` attribute (Node), read per report; each log line that starts with `FAILED `, `ERROR ` or `--- FAIL`, or holds ` FAIL `, added after the JUnit cases when no JUnit case failed or a report does not parse), `slowest` (JUnit XML in `DEVLOOP_REPORT_DIR`, else `[]` and `hint`), `seal` (the `seal-check --uncommitted` payload; the process exits 1 when `seal.ok` is false, even if the project gate passed; the JSON `exit` stays the project gate's own exit), `weakened` (list of `{path, reason}`, `reason` `skip-added` or `assertions-removed`, for test files in `git diff <base>`; report only, never changes the exit code), `size` (the `size-check --uncommitted` payload; the process exits 1 when `size.ok` is false).
