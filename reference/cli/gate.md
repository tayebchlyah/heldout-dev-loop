# gate

- `gate --summary`: `commands.gate`, else `scripts/gate.sh`. JSON `exit`, `log`, `seconds`, `failures` (each failed or errored JUnit case as `FAILED <classname>::<name>`, prefixed `<file>::` when the case has a `file` attribute (the path relative to the repo top when under it, else as given), read per report; `FAILED <report>.xml: report does not parse` per broken report; `FAILED <report>.xml: report missing` per report the previous gate run of the worktree (newest other `gate-*-reports` folder with an XML) wrote and this run did not, none on a first run; each log line that starts with `FAILED `, `ERROR ` or `--- FAIL`, or holds ` FAIL `, added after the JUnit cases when no JUnit case failed or a report does not parse or is missing), `slowest` (JUnit XML in `DEVLOOP_REPORT_DIR`, else `[]` and `hint`), `seal` (the `seal-check --uncommitted` payload; the process exits 1 when `seal.ok` is false, even if the project gate passed; the JSON `exit` stays the project gate's own exit), `weakened` (list of `{path, reason}`, `reason` `skip-added` or `assertions-removed`, for test files in `git diff <base>`; report only, never changes the exit code), `size` (the `size-check --uncommitted` payload; the process exits 1 when `size.ok` is false).
