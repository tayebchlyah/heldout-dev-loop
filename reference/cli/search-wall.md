# search-wall

- `search-wall`: stdin one PreToolUse hook JSON object (Claude or Codex: `tool_name`, `tool_input`, `cwd`, `agent_id`, `agent_type`). JSON `{"deny": bool, "reason": string|null}`; `reason` is the block line when `deny` is true. Exit 0 for allow and deny, 2 on a usage error. Input that is not a JSON object: `deny` true, `reason` `Blocked: guard error: hook input is not a JSON object`. Reads no file; runs `git rev-parse` for the tops.
- Who: every subagent (`agent_id` set) but `spec-tester` and `spec_tester`. The main session is allowed.
- Suite: `tests/acceptance` under the git top of `cwd`, and of `$CLAUDE_PROJECT_DIR`, each only when that top holds `dev-loop.json` and the folder `tests/acceptance`. None: allow.
- Search: `Grep`, `Glob`; in `Bash` and Claude `Monitor` (decided as `Bash` on its `command`, #97), a simple command (split on `;`, `&&`, `||`, `|`, `&`, newline, `(`, `)`, backtick; redirections dropped; heredoc bodies removed) whose command word (after `VAR=value` and shell keywords, basename) is `grep`, `egrep` or `fgrep` with a recursive option, `rgrep`, `rg`, `git ... grep`, or `find`. Wrappers (`xargs`, `env`, `sh -c`) are not followed. A command the tokenizer cannot parse (an unclosed quote) that holds a search word: deny.
- Root: the current folder is `cwd`, moved by each `cd` or `pushd`. `Grep` `path`, else the folder. `Glob` `path` joined to `pattern`. `grep`, `rg`: the operands after the pattern (none with `-e`, `-f`, `--regexp`, `--file`, rg `--files`); value-taking options skip their value. `git grep`: the pathspecs (an operand before `--` that is not an existing path is a revision), else the folder or the `-C` folder. `find`: the operands before the first `-`, `!` or `(` token. `~` is `$HOME`. A root with wildcards or braces reaches the suite when it can match the suite, a path in it, or a folder above it. Normalized: lower case, `.` and `..`, doubled slashes, `/private`.
- Deny: a root inside the suite, always; a root above it, unless the call excludes the suite: grep `--exclude-dir` matching `acceptance` or `tests`; rg `-g`, `--glob`, `--iglob` `!G`; `Grep` `glob` `!G` (G: `acceptance`, `tests` or `tests/acceptance`, give or take a leading `/`, `./`, `**/` and a trailing `/`, `/**`, `/**/*`); git `:!P`, `:^P`, `:(exclude)P` with P the suite or a folder above it; find `-path P -prune` (or `-ipath`, `-wholename`), `-name N -prune` (N matches `acceptance` or `tests`), `-not -path P` or `! -path P` with P matching every file of the suite. A `Glob` that can match a file in the suite is denied (no exclusion form).
- Callers: `deny-acceptance-to-subagents.sh`, `deny-path.sh tests/acceptance` (Claude), `acceptance-wall.sh` (Codex), only for `Grep`, `Glob` or a `Bash` or `Monitor` command that holds a search word. CLI `.agents/skills/dev-loop/scripts/devloop.py` under the git top of `cwd`, else `$CLAUDE_PROJECT_DIR` (Claude); none: the search rule is skipped. A non-zero exit or no JSON object: the wall blocks with `Blocked: guard error: search check failed`.
