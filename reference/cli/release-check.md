# release-check

- `release-check [--repo <path>] (--tag <name> | --sha <rev>)`: may a commit get a release tag. Release tag: `v*` (`fnmatchcase`); another `--tag` name: `ok` true, `skipped` `not-a-release-tag`. Target: `<tag>^{commit}`, or `--sha`. Project note: `$NOTES/Project Note.md`, else `$NOTES/<notes folder name>.md`. Reasons, in order: `no-audit` (no current record, the last `## Release audits` bullet `- <date> run-<N> at <sha>: confirmed <n>, needs validation <n>, hardening <n>, profile <p>, scope <s>`), `record-mismatch` (`detail`: run folder `$NOTES/security-audit/run-<N>/run-metadata.json` missing, unparsed, `source_ref.commit` other than the record sha, or `run_status` not `complete`), `stale-audit` (`paths`: the record sha is not the target, and not an ancestor with only test or doc paths in the diff), `open-security` (`items`: a `## Deferred` top-level bullet `<date> (security, confirmed|needs-validation, <run-N or slug>): <text>`; `confirmed` open until its line is removed, `needs-validation` closed by a sub-bullet `- Ruling <date>: accept|close <reason>`), `unparsed-security` (`lines`: a bullet with the word `security` that does not match: fails closed). JSON `ok`, `tag`, `target`, `record`, `reasons`. Exit 0 when `ok`, else 1. No kit copy rule: a kit copy left out by `release-plan` `exclude` still makes the audit stale, a new record is needed. Exit 1 with `error`, no `ok`: no repo, tag or rev unresolved, notes path unresolved, `no-project-note`, `cannot read <note>: <ExcType>`. Exit 2 usage. The git guards run it on a `v*` tag push and `gh release create`.

Release commit: when the record sha is an ancestor of the target, a changed path that is not a test or doc path still leaves the audit current if `ci-skip` allows it (`CHANGELOG.md`, a version-only change of a `version_files` path, a `dev-loop.json` change of `version` only, the kit copies of a kit upgrade; rules in `reference/cli/ci-skip.md`). Any other code path makes the audit stale, and `paths` lists every non-test, non-doc changed path. A bad `version_files` at the target fails closed to `stale-audit`.
