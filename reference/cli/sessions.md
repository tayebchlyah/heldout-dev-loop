# sessions

- `sessions --since <days> [--repo <path>]`: the Claude Code and Codex main sessions of every worktree (`git worktree list`, realpath), for retro. Window start: now (UTC) minus `<days>` x 24 h; listed when the last record `timestamp` is at or after it; files with an mtime before it skipped. Claude: `$CLAUDE_CONFIG_DIR/projects` (default `~/.claude`), the worktree folder as `metrics` names it, `*.jsonl` (session: the stem), `<stem>/subagents/agent-*.jsonl` added. Codex: `$CODEX_HOME/sessions/**/rollout-*.jsonl` (default `~/.codex`), line 1 `session_meta`: string `source` a main session, its worktree the longest worktree path equal to or a `/` prefix of `realpath(cwd)` (none: not listed); `thread_spawn` `parent_thread_id`: added to that listed main; other object `source` (guardian): not listed. JSON `since`, `sessions`: `harness`, `session`, `path`, `worktree`, `feature` (branch `<prefix>/<slug>`), `start`, `end` (UTC `YYYY-MM-DDTHH:MM:SSZ`), `bytes` (with subagents), `subagents`, `stage` (`board-state.json` `stage_times` key with the latest time at or before `start`), `first_request` (first typed prompt; Codex skips `<` and `# AGENTS.md instructions`; 200 characters or less, or null). Order: `bytes` descending, `start`, `path`. Exit 1 with `error`: not a git repo. Exit 2: `--since` missing, not an integer, below 1.
