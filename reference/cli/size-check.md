# size-check

- `size-check [--uncommitted | --all]`: file-size ratchet, limit 40,000 bytes (over: more). `<base>` as `seal-check`. Default: paths of `git diff --name-only --no-renames <base> HEAD` present at `HEAD`, `HEAD` blob size. `--uncommitted`: `git diff --name-only --no-renames <base>` plus untracked not ignored, working tree size. `--all`: `git ls-files` plus untracked not ignored, no base. Skipped: symlink, gitlink, binary (NUL in the first 8,000 bytes), a `files` key of `.dev-loop/MANIFEST.json`, a merged config file `upgrade` writes (`.claude/settings.json`, `.codex/hooks.json`, `.codex/config.toml`) and its `.bak-<stamp>` backup beside it, a `file_size_exempt` match (`dev-loop.json` of the working tree, `fnmatchcase`, `*` matches `/`). `reason`: `new` (absent at `<base>`, a moved file too), `grown` (more bytes than at `<base>`, net over the branch), `over` (`--all`). Violation: `path`, `reason`, `bytes`, `base_bytes`, `seam` (`{line, name}`: the unit start after line 1 nearest the byte middle, or null), `units` (3 largest `{name, start, end}`, by bytes), `hint`. Unit starts at column 0: `.py` `class `, `def `, `async def `; `.js .mjs .cjs .ts .tsx .jsx` `export `, `function `, `async function `, `class `, `describe(`; `.md` `## `; `name` at most 80 characters. No `<base>` (not `--all`): `ok` true, `skipped` `no-base`. JSON `ok`, `mode` (`committed`, `uncommitted`, `all`), `base` (null for `all`), `limit`, `violations`. Exit 0 when `ok`; 1: a violation or `error` (a bad `file_size_exempt`); 2: outside a git repo, `--uncommitted` with `--all`.
