# cleanup

- `cleanup --branch <branch> [--repo <path>]`: the Stage 7 post-merge cleanup, git only (never `git push`, `gh`, `--force`, `--autostash`, `git stash` or `git reset`; GitHub deletes the remote branch with "Automatically delete head branches"). Usage errors (exit 2, `{"error": ...}`): no `--branch`, `--branch` `main` or `master`, `--repo` not in a git repository. Main checkout: the first entry of `git worktree list --porcelain` of `--repo` (any folder of any worktree of the repo); every git command runs there except the worktree `status` and `rev-parse`. Order: `git fetch origin --prune` (fails: `worktree`, `branch`, `main` all `skipped`, one reason `fetch: <line>`, nothing else runs), then the worktree, the branch, the main checkout; the main part runs when the worktree part skips. Merged: `git cherry origin/main refs/heads/<branch>` exits 0 and lists no `+` line. Worktree of the branch: the porcelain entry with `branch refs/heads/<branch>` (a detached worktree is not matched). Worktree checks, first failing wins: `main-checkout` (the branch is checked out in the main checkout), `in-use` (the process cwd, physical path, is the worktree or inside it), `not-merged`, `dirty` (`git status --porcelain` prints a line or fails: a folder deleted by hand), `paused` (`<worktree git-dir>/dev-loop/pause.json`); then `git worktree remove <path>`, no `--force` (ignored files do not block it; fails: `remove-failed: <line>`). Branch: a kept worktree gives `skipped`, `worktree-kept`; no `refs/heads/<branch>`: `absent`; not merged: `not-merged`; else `git branch -D` (a rebase merge gives new hashes, `-d` refuses; fails: `delete-failed: <line>`). Main checks, first failing wins: `not-on-main` (another branch or detached), `operation-in-progress` (`rebase-merge`, `rebase-apply`, `MERGE_HEAD`, `CHERRY_PICK_HEAD` or `REVERT_HEAD` in its git dir), `dirty` (a tracked change, staged or not; untracked files do not count), `local-commits` (`origin/main..HEAD` not empty); `HEAD` equal to `origin/main`: `current`; else `git rebase origin/main`, a failure runs `git rebase --abort`: `rebase-failed: <line>`. `<line>`: the first non-empty line of stderr, else stdout, else `exit <code>`. Output: `target` (the branch), `path` (the worktree path as git prints it, or null), `worktree` (`removed`, `absent`, `skipped`), `branch` (`deleted`, `absent`, `skipped`), `main` (`rebased`, `current`, `skipped`), `reasons` (each `<part>: <word>`, in part order). Exit 0 when `reasons` is empty, else 1.
