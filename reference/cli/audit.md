# audit

- `audit`: SubagentStop hook JSON on stdin (`agent_id`, `agent_type`, `agent_transcript_path`, `cwd`). Compares the subagent's tool output with the files it must not read (`spec-tester`: `src/`, `app/`, `backend/`, `frontend/`; any other: `tests/acceptance/`). 2 or more distinct distinctive lines (30 characters or more): a taint record in `<git-dir>/dev-loop/taint.json`; no `<agent_id>.head`: the range starts at `<base>`, else the root. A re-stop replaces the agent's record or skip. JSON `taint` (record or null), `skipped`. The path rule (any subagent but `spec-tester`): a line of a search output (a `Grep` or `Glob` result, or a `Bash` call or Codex `CommandExecution` whose command holds `grep`, `egrep`, `fgrep`, `rgrep`, `rg` or `find` as a whole word; a Claude `tool_result` is paired with its call by `tool_use_id`) that starts with the path of a held-out file (`tests/acceptance/<rest>`, with any `<dir>/` before it, or `acceptance/<rest>`, `./acceptance/<rest>`; then the end of the line, `:`, `-`, a NUL or whitespace) taints alone; one path is enough. Listings and gate output are not search outputs. A record holds `paths` (the matched suite paths, sorted, at most 3; `[]` for a line-only taint); an older record without it still loads. Exit 0, also on a skip.
