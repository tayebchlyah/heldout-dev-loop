# upstream.json

- `upstream.json`: outside sources dev-loop copies or invokes, each `repo`, `signal` (`release`: latest GitHub release tag; `plugin-version`: `version` of `file` at its last commit; `tree`: tree id of `folder` at the default branch head), `pin` (compare base), `version` (the text each `local` file cites, a guard test checks it), for `tree`: `folder` (path of the watched folder) and `tree` (the pinned tree id, cited in a `local` file too), `paths` (watched upstream files, `/` end: folder), optional `ignored` (a latest value to skip). `scripts/upstream_watch.py` (`--dry-run`: body in the JSON, no issue): compares each pin, keeps one open issue labelled `upstream-watch` (edits it, else creates it) with the diffs of watched files; nothing new: no write; a failing source gets `state` `error`, the others still count, exit 1 with `error`. `--sources <file>`: another list. Run weekly by `.github/workflows/upstream-watch.yml`. Repo only, not in the kit. Upgrade or re-copy: move `pin`, `version` (and `tree` for a `tree` source) with the cited text; ignore: set `ignored`.
