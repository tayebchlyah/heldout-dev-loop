# upstream.json

- `upstream.json`: outside sources dev-loop copies or invokes, each `repo`, `signal` (`release`: latest GitHub release tag; `plugin-version`: `version` of `file` at its last commit; `tree`: tree id of `folder` at the default branch head), `pin` (compare base), `version` (the text each `local` file cites, a guard test checks it), for `tree`: `folder` (path of the watched folder) and `tree` (the pinned tree id, cited in a `local` file too), `paths` (watched upstream files, `/` end: folder), optional `ignored` (a latest value to skip). `scripts/upstream_watch.py` (`--dry-run`: body in the JSON, no issue): compares each pin, keeps one open issue labelled `upstream-watch` (edits it, else creates it). Per new source: the diffs of watched files; the commits of the compare range that changed one (short sha linked, subject; a range over the compare list: a line says so); `release` only: each release after the pin, pre-releases and drafts skipped, in pages of 20 up to 5 (pin not found: a line says so), each a collapsed block with its notes cut at 3,000 characters and its link. Upstream text goes in code (a subject in a code span, notes in a fenced block): no `@` ping, no `#N` link to this repo, no mention entry upstream. Body over 65,536 characters: drop the diffs, then the note bodies (links kept), then the commits. Nothing new: no write; a failing source gets `state` `error`, the others still count, exit 1 with `error`. `--sources <file>`: another list. Run weekly by `.github/workflows/upstream-watch.yml`. Repo only, not in the kit. Upgrade or re-copy: move `pin`, `version` (and `tree` for a `tree` source) with the cited text; ignore: set `ignored`.
